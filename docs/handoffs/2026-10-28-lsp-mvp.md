## Completed work

### #48 — EUD player warning

The shared LSP analysis layer now warns when `Deaths`, `DeathsX`, `SetDeaths`, or
`SetDeathsX` uses a group player selector with a unit constant above the stock
boundary (232). Stock filters, stock unit IDs, concrete players, variables, and
ambiguous expressions stay silent. The rule is shared by Python, TypeScript,
JavaScript, TSX, and JSX. It lives in the shared analysis layer so the compiler can
reuse it later.

Key file: `src/rust/eudkit-lsp/src/analysis/eud_player.rs`.

## EWait / StarCraft 64-bit work — not ticketed

This is separate from the LSP MVP. The analysis is complete, but no GitHub issues

1. No-EWait resource text first (recommended).
2. Full EWait parity.
3. Both, as separate tracks.

### What EWait does

`EWait.py` (version `0.0.33`, `ignore64 = True`) is a CP-trick write primitive. It
sets `0x6509B0` to an out-of-range index and runs a `Wait` action, which writes the
action time into the per-player wait-timer array. `_SetEWaitCP` also patches fixed
offsets in a 2408-byte in-memory trigger.

Constants:

- `Address_WAIT = 0xDB8714`
- `Address_WAIT_FLAG = 0xDB870C`

Resource-line handling:

- `init_resource_line()` calls `SetEWait(0xD7DCD8, 0x80000000)` and writes
  `0x02020000` with mask `0xFFFF0000` at `0x640B60 - 2 + 218*11`.
- `f_displayResourceText()` writes at `0x640B60 + 2 + 218*11`.
- `display_at(11)` writes at the line base, not at `+2`, and does not freeze the
  resource-line updater.

### Why 64-bit is unresolved

The 64-bit Wait-array/flag addresses and the 64-bit resource-line target are
undocumented. The EUD Book's `0x650980` "Trigger Wait Timers" is a different
structure. The resource-line freeze itself only needs a constant write, so a direct
`SetMemory` may replace EWait if the 64-bit target addresses are stable.

Relevant files:

- `EWait.py` — **untracked local file, not in git**. Copy it separately if needed.
  Do not commit `EWait.py:Zone.Identifier`.
- `src/rust/eudkit-core/src/lir/trigger_emitter.rs` — display-buffer lowering at
  `0x640B60 + 218 * line`.
- `src/eudkit/types.py` — `SetMemory`, `SetMemoryX`, `display_at`, `IsUserCP`.
- `src/eudplib/eudlib/wireframe/wireframe.py` — `Is64BitWireframe()`.
- `eud-domain-knowledge/README.md` — gitignored local engine notes.
